QA OS Setup Guide

How to install QA OS on your own PC so you can train and use Claude for S&D testing. It takes about 20 minutes. Do it once per PC.

Before you start: what you need

  • A Windows PC.
  • Google Chrome.
  • Python 3.10 or newer (python.org). During install, tick “Add Python to PATH”.
  • Node.js LTS (nodejs.org). Use the default options.
  • The Claude desktop app, signed in with your own Claude account.
  • The release file qa-os-v0.5.0.zip.
  • The database logins from the QA Team Lead: one for the S&D database, one for the framework database. For each you need host, port, database name, user, password and schema.
Never share passwords in chat or email. You type them only on your own PC, when the setup asks.

Step by step

The examples use drive C:. You can use any drive (for example D:); just change the letter.

1

Put QA OS on your drive

Right-click qa-os-v0.5.0.zip → Extract All → choose C:\ (the root of the drive) → Extract.

You now have the folder C:\qa-os.

Check: the file C:\qa-os\CLAUDE.md exists.
Do not extract into C:\qa-os, or you get C:\qa-os\qa-os. If that happens, move the inner folder up one level.
2

Connect the tools (browser and databases)

Open C:\qa-os\connectors and double-click setup_mcp.bat. The setup:

  1. checks Python, Node.js and Chrome;
  2. installs the database tool (it can only read data, never change it);
  3. asks for the S&D database login, then the framework database login. The password is hidden while you type. Press Enter to accept a default shown in [brackets];
  4. tests each connection;
  5. saves everything into your Claude app settings, after making a backup.
Check: you see “connected (… tables visible)” for both databases and “Saved …claude_desktop_config.json”.
3

Install the Python packages

Open Command Prompt and type:

cd /d C:\qa-os
python -m pip install -r requirements.txt
Check: it ends with “Successfully installed …” or “Requirement already satisfied”.
4

Restart the Claude app

Close the Claude desktop app completely: right-click its icon near the clock (system tray) → Quit. Then open it again.

5

Open the QA OS folder in Claude

  1. Go to the Code tab.
  2. Open the folder C:\qa-os itself, not a folder inside it and not C:\.
  3. When Claude asks to trust the folder, choose Yes.
  4. When it asks to install the qa-os plugin, accept.
6

Choose the right permission mode

Under the message box, set the mode selector to Ask permissions (not Auto). The first time Claude uses the browser, choose Always allow for the selenium tools.

7

Optional: connect Jira

Only needed for ticket work, not for training. On claude.ai: Settings → Connectors → Atlassian → Connect. Sign in with an Atlassian account that can open SDMS tickets. Then, in the app, turn it on with + (next to the message box) → Connectors → Atlassian.

Test that it works

Start a new chat in C:\qa-os and try these three things:

Type thisYou should see
Which connectors does this session have?selenium, snd-schema and selenium-framework-db as connected
What do you know about this QA OS setup so far?An answer that mentions docs/STATUS.md and the S&D business knowledge
/qa-os:statusA list of runs and a summary of the S&D app

If all three work, you are ready. Start training with /qa-os:train snd (see the User Manual).

If something goes wrong

ProblemWhat to do
Setup says “Python not found”Reinstall Python and tick “Add Python to PATH”. Close and reopen the window, then run the setup again.
Setup says “Node.js (npx) not found”Install Node.js LTS, restart the PC, run the setup again.
A database “could not connect”Check you are on the office network or VPN, and check the host, port and password with the QA Team Lead. Run the setup again; it replaces the old values.
A connector shows “failed” in ClaudeQuit Claude fully (system tray → Quit) and open it again. If it still fails, run the setup again.
/qa-os:train is not foundMake sure you opened C:\qa-os itself, and that C:\qa-os\.claude\settings.json exists. Restart Claude and accept the plugin install.
Claude is blocked from typing values in the appSwitch the mode selector from Auto to Ask permissions.
Claude asks you for a passwordIt should never do that. Say: “I will log in myself.” Type passwords only in the browser window.

Updating to a new version later

  1. Keep your work: if you trained Claude, send your changes back first (Training Guide, section 6).
  2. Rename the old folder (for example C:\qa-os-old) and extract the new zip to C:\.
  3. You do not need to run the setup again, unless the release notes say so or a database login changed. If you do run it, point it at the new folder.
  4. Restart Claude and open C:\qa-os again.

Safety rules

  • Claude never types user names or passwords. You log in yourself in the browser.
  • The database tools can only read. Claude never runs changes on any database.
  • Your passwords stay in your own Claude settings on your PC. Never put them in the qa-os folder, in git, or in chat.
  • On the shared test environment, only one person runs the daily cycle for a distributor on a given day.
